### Download Ultraglass

```shell copy
mkdir /etc/hyperglass
cd /opt
git clone https://github.com/WilhelmZA/ultraglass.git --depth=1
cd /opt/ultraglass
```

### Optional: Quickstart

Do this if you want to verify the Ultraglass page with a fake device before connecting real network devices.

```shell copy
cp /opt/ultraglass/.samples/sample_devices.yaml /etc/hyperglass/devices.yaml
cd /opt/ultraglass
docker compose up
```

Navigate to http://localhost:8001

### Create a `systemd` service

<Callout type="info">
    Before you create and start the Ultraglass service, verify whether you need to change any
    [environment variables](environment-variables.mdx).
</Callout>

```shell copy
cp /opt/ultraglass/.samples/hyperglass-docker.service /etc/hyperglass/hyperglass.service
ln -s /etc/hyperglass/hyperglass.service /etc/systemd/system/hyperglass.service
systemctl daemon-reload
systemctl enable hyperglass
systemctl start hyperglass
```
